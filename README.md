# গ্রুপ তহবিল — ফাইল তালিকা
- index.html — অ্যাপ (কোড বদলালে শুধু এটি আপলোড)
- config.js — Firebase সেটিং + অ্যাডমিন তালিকা (mamun, shorif)
- sw.js — অফলাইন/আপডেট (VERSION বাড়ালে সবাই নতুন ভার্সন পায়)
- manifest.json, icon-192.png, icon-512.png — ইনস্টলের জন্য
- capacitor.config.json, package.json — APK বানানোর জন্য
- firestore.rules — Firebase Rules (Firestore → Rules এ পেস্ট করে Publish)
APK: GitHub → Actions → Build APK → Run workflow → Releases থেকে GroupFund.apk
